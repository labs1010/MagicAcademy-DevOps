# Джерела вимог і технічних рішень

Прикріплені методички прочитані повністю:
1. «Лабораторна робота 1 (1).pdf», с. 1 — 6 основних + 4 додаткових бали.
2. «Лабораторна робота 2 (1).pdf», с. 1–2 — 5 + 5 балів.
3. «Лабораторна робота 3 (1).pdf», с. 1–2 — 7 + 3 бали, обрано варіант A.
4. «Лабораторна робота 4 (1).pdf», с. 1 — 2 + 2 + 3 + 3 бали.
5. «Лабораторна робота 5 (1).pdf», с. 1–2 — 8 + 2 бали.
6. «Варіанти Предметної Області (1).pdf», с. 4 — фентезі №2.

Технічні первинні джерела (перевірено 2026-11-02):
- https://www.postgresql.org/docs/current/sql-select.html — SELECT FOR UPDATE.
- https://docs.sqlalchemy.org/en/20/core/selectable.html — with_for_update.
- https://docs.docker.com/compose/how-tos/startup-order/ — service_healthy.
- https://docs.docker.com/compose/gettingstarted/ — named volumes.
- https://docs.locust.io/en/2.37.11/retrieving-stats.html — CSV/history.

Методички мають пріоритет над довільними побажаннями. Суперечностей зі стеком немає.
Вони не вимагають хмарного розгортання, якщо обрано CI/CD варіант A, окремого frontend,
реалізованого кешу або міграційної бібліотеки для незмінної початкової схеми.
